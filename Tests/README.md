# 必要回归

在项目目录执行：

```sh
scripts/run-regressions.sh
```

需要 Xcode 及其 macOS SDK。可通过 `LOCALPASTE_TEST_OUTPUT` 指定产物目录；默认使用新的临时目录。脚本先用冻结的旧模型生成含 WAL、收藏、分类和大附件的人工旧库，再编译当前产品代码并运行回归。成功以 `ALL_REGRESSIONS_PASSED` 结束。

验证覆盖旧库复制与重开、不同应用数据隔离、不兼容旧库拒绝、存储失败回滚、暂停期间内容丢弃、HTML/RTF 文字提取、文件引用、concealed 跳过、连续粘贴及外部剪贴板变化、分类状态、取消收藏后的上限和缓存搜索。

滚轮回归验证正反方向转换、精细像素距离与手势阶段保留，以及横向、斜向事件保持原样。测试事件只在内存中转换，不发送给系统；视口范围、点击和实际移动使用人工界面验证。

所有内容均为人工样例。数据库位于临时目录；粘贴和采集使用独立命名的 NSPasteboard，权限、前台目标及按键交付由受控环境替换。没有打开真实数据库或访问通用剪贴板，也不调整系统权限、快捷键和登录项。预期的只读数据库写入拒绝可能产生 Core Data 诊断日志，是否通过以断言和退出码为准。

生成的 `regressions` 可用 `--ui` 启动人工界面验证。界面使用产品视图和面板；实际写入只发生在独立命名剪贴板，未请求辅助功能权限、未注册全局快捷键、登录项开关禁用。菜单提供打开历史、设置和退出。该副本不能替代安装版的真实自动粘贴、登录启动或多屏验收。
