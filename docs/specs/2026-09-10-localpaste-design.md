# LocalPaste：Mac 本地剪贴板设计

状态：历史设计记录；方向已获用户确认并已完成初版实现，当前验证状态见 `../verification/STATUS.md`。LocalPaste 是工作名，不代表已做商标或名称可用性检查。

## 目标与边界

为 Prince 从零实现可安装、自用的 macOS 原生剪贴板 App，借鉴 Paste 的底部卡片、键盘导航、预览与收藏分类工作流。代码与视觉素材独立实现，不复制 Paste 品牌或专有资源，不 fork 第三方代码。本期只支持 Mac 本地；不包含 iOS、iCloud、账号、AI、OCR、批量顺序粘贴、遥测或对外发布。

技术选择：Swift、SwiftUI + AppKit、SwiftData，macOS 14+；XcodeGen 生成项目。开发环境已确认 Xcode 26.0 和 XcodeGen 可用。优先系统 API，不引入第三方依赖。生产 Hermes Gateway 不属于项目作用域，不停止、重启或修改任何服务。

## 用户流程

App 常驻菜单栏，无常驻 Dock 图标。菜单提供打开面板、暂停/恢复采集、设置、退出。默认全局快捷键 Command-Shift-V，冲突时设置中可修改；注册失败须显示实际错误，不能静默失败。

复制后采集支持的剪贴板类型。呼出时记住当前目标应用，在鼠标所在显示器底部显示横向卡片面板。面板可聚焦搜索框，但不得激活时丢失原目标应用。点击卡片或 Enter 执行粘贴；左右键选择，Escape 关闭，Space 显示预览。底部面板原生材料背景、中性色、青色选择强调，卡片显示内容预览、类型、来源应用及时间；只借鉴布局原则。

顶部显示搜索框、全部历史及收藏分类。支持创建/重命名/删除分类、将条目加入或移出一个分类。删除分类保留原条目。搜索文本、标题和来源应用，不承诺图片 OCR 或文件内容索引。右键支持纯文本粘贴、分类、删除。清空历史需要确认，默认保留收藏；删除操作限本 App 数据，不删除原文件。

## 组件和数据流

ClipboardMonitor：主线程 Timer 有界间隔检查 NSPasteboard.changeCount。只读取支持的 pasteboard 类型，不记录启动前已有的剪贴板内容。尽可能保存每个 pasteboard item 的支持表示，保留富文本/HTML 与纯文本并存信息及多文件引用。检测文件 URL 优先于普通字符串。自身写回通过 changeCount 抑制再采集。

HistoryStore：SwiftData 存储条目 UUID、时间、来源应用标识和名称、显示标题、内容类型、各 pasteboard item 表示与分类关系。图片等较大 Data 使用外部存储属性。文件存引用不复制文件本体，因此文件被移动/删除后引用可能失效；界面明确提示，不声称文件归档功能。数据库位于 App 自己的 Application Support 目录。

PanelController：AppKit NSPanel 承载 SwiftUI 卡片视图，处理呼出、目标应用、显示器可见范围、收起与焦点。Preview 使用独立原生预览视图展示文本/富文本、图片或文件信息；本期不将网页内容联网抓取。

PasteCoordinator：恢复原类型表示到系统剪贴板；纯文本操作只写字符串。获辅助功能授权后激活记住的原应用，确认其前台状态再发送 Command-V。没有授权时内容仍复制成功，并清楚显示“已复制，按 Command-V 粘贴”，不伪装自动粘贴成功。不在权限未授予时循环弹窗，不对未知目标自动发送按键。

Settings：UserDefaults 保存快捷键、历史上限、暂停状态、排除应用；默认普通历史上限 500 条，收藏不参与淘汰；删除时清理本 App 外部资源。常用快捷键录制与系统冲突提示采用实际注册结果。

## 必要隐私边界

本地存储不是加密保险箱，不宣称绝不记录敏感内容。跳过系统 concealed/transient 标记。默认排除常见密码管理器，并允许用户通过应用选择器追加排除项；读取被排除应用产生的事件时直接跳过。应用来源是最佳努力识别，通用剪贴板等事件不保证可归因。第一版不增加密钥识别 AI，不上传历史，不自动接入 KnowledgeOS 或 Hermes。

## 开发与验收

遵循功能优先：先实现 happy path 并实际运行，不先建立新测试工程、兼容层或无关硬化。需要系统权限或人工桌面操作时明确请求，不绕过系统权限。不为验证读取用户原有私人剪贴板历史；用明确标记的人工样例。

验收必须记录实际输出与观察，不能以编译通过代替运行通过：

1. XcodeGen 生成、xcodebuild 编译成功，生成真实 .app；打开后菜单栏可操作。
2. 人工样例文字/链接、图片、富文本和 Finder 文件引用采集与预览正常。
3. 从 TextEdit 等目标应用呼出，选择条目自动粘贴返回原应用；纯文本粘贴去掉格式。辅助功能未授权时如实记录阻塞。
4. 搜索、键盘选择、分类持久化可实际使用。
5. 退出并重开后样例历史与分类仍存在。
6. 暂停及排除应用不产生新历史；历史上限和清空按界面行为工作。
7. 多显示器实际呼出观察；如仅有一台显示器则标记未验证，不把几何计算或模拟结果当成真机验收。

验收后交付 App 路径、已验证项目和未验证/受阻项目，停止扩展，等待 Prince 使用确认。运行权限由用户授权。第一版仅本机构建，不承诺签名公证或可分发安装包。
