# 2026-09-11 日用体验改版

正常使用时只展示操作和当前状态。设置拆分为通用、隐私、分类、关于；数据库路径、系统错误码、重复的成功说明和验证副本说明不再占据常用页面。需要排查时，仍可打开错误详情和版本详情。

## 界面与交互

- 通用页使用正向“记录剪贴板历史”开关和简短状态；保留条数、登录启动和打开历史快捷键集中在一页。
- 快捷键直接点击修改，Esc 或取消按钮保留原值；自绘控件提供按钮语义和当前值。
- 隐私页显示当前进程的辅助功能授权状态、应用图标和名称；仅在需要时提供授权入口，保留简短的排除限制提示。
- 分类管理独立呈现，重命名和删除收纳在菜单中。重命名面板由所选分类驱动，首次打开即带入原名称，避免空白初始值。
- 历史页缩短搜索占位文字，使用轻量按键提示；清空操作移到更多菜单，仍保留原确认步骤。暂停和无搜索结果提供直接恢复入口。
- 预览减少重复标题。文件以名称和位置呈现，可在访达中定位；原文件缺失时提示并禁用定位操作。
- 重新打开无窗口的 App 时展示历史，并增加应用菜单中的历史入口。

## 构建交付

产品版本由 `project.yml` 管理。`scripts/build-release.sh` 生成 App、ZIP、日志和源码摘要，写入构建号与修订；未提交修改显式标记为 dirty。可指定本机稳定签名身份，脚本不自动覆盖日用 App。

macOS PR 工作流复用现有回归和构建脚本，使用固定 action 提交，权限限于读取仓库，并保存未签名检查产物。远端实际执行结果以 PR 检查为准。

## 已验证与边界

37 项隔离回归断言通过。隔离 GUI 已检查四个设置页面、快捷键取消、记录开关的可访问名称、分类重命名初始值和保存，以及文件定位和缺失提示；访达实际选中了人工文件。验证只使用独立数据库和人工内容。

辅助功能状态显示只代表系统授权状态；真实自动粘贴、全局快捷键和后续登录启动仍需分别记录实际结果。产品界面改版不改变数据模型或历史保存位置。
