# 2026-09-11 全库审查修复

覆盖审查报告 F01–F12，以及报告列出的界面改进。修改基于审查时包含未提交 UI/登录项改动的工作区，保留了这些已有工作。源码修复阶段使用隔离数据；随后按用户授权完成日用 App 替换和真实历史迁移，旧 App 与完整旧库已备份，原历史未清空。安装结果见 [验证状态](../verification/STATUS.md)。

## 修复对应

| 审查项 | 实现 |
|---|---|
| F01 数据隔离 | `ClipboardPersistence` 按 Bundle ID 使用专属目录。旧库模型匹配后，用 Core Data 复制 API 暂存数据库及附件，校验所有内容后整体发布；旧库保留。不兼容或不完整数据停止启动并展示错误，不静默创建空历史。阻止同 Bundle ID 的多个版本同时运行。 |
| F02 暂停边界 | 监视器同步观察暂停状态，在切换时重置剪贴板计数和来源基线；恢复前积累的变化不补录。 |
| F03 菜单状态 | 菜单订阅暂停状态，设置中的变更立即更新菜单文字。 |
| F04 粘贴竞争 | 同时仅接受一个粘贴操作，延迟发送前检查剪贴板版本；外部复制会取消本次自动粘贴。所有结束路径释放进行中状态。 |
| F05 滚动跟随 | 选中 ID 变化时，横向列表将对应卡片滚入视野。 |
| F06 焦点一致 | 卡片焦点同步到选中项；卡片自行处理 Enter/Space，其他控件保留原生按键行为。 |
| F07 分类状态 | 存储变更同步刷新筛选结果；已删除的分类回到全部，收藏/分类成员移除后修正选中项。 |
| F08 错误反馈 | 历史和设置显示存储错误。分类使用可保留输入的编辑面板，失败不关闭。保存失败回滚，显式检查只读配置及未保存状态。 |
| F09 HTML 正文 | 使用 SDK 自带 libxml2 离线提取正文、实体和段落；新条目及旧条目的搜索摘要均可获得正文。无可用文字的内容不再把类型标签当作纯文本粘贴。 |
| F10 搜索性能 | 内存缓存小型内容摘要，筛选不再读取 payload；可见结果仅在查询、分类或存储变更时更新。 |
| F11 收藏上限 | 取消收藏后重新执行普通历史淘汰。 |
| F12 分类重名 | 创建与重命名使用同一套空白处理和唯一性校验，允许当前分类保持自身名称。 |

## 同步完成的界面改进

- 设置、预览与历史统一跟随系统外观；富文本内容用原生文档视图保留字体、颜色及附件。
- 预览增加明确的关闭按钮、Esc 快捷键及无障碍名称。
- 避免普通卡片重复显示相同标题和首行，增加粘贴/预览操作提示。
- 区分无历史、已暂停、空收藏、空分类和无搜索结果。
- 自绘快捷键录制区域公开可访问的名称、当前值和使用提示。
- README、首次运行文档和下一阶段计划同步反映当前实现及安装验收边界。

## 验证

必要回归入口：`scripts/run-regressions.sh`，使用冻结旧模型生成合成旧库，再编译当前产品代码。Release 构建通过；37 项断言通过，包括：

- 旧库 WAL 与大附件复制、条目/分类/收藏/ID 保留、旧库不改写、重开不重复导入，以及不同 Bundle ID 和不兼容库的处理。
- 暂停与恢复之间的复制丢弃、恢复后新复制采集、concealed 跳过、HTML/RTF 正文与 Finder 多文件引用。
- 连续提交只发送一次、剪贴板变化取消发送、纯文本移除富文本表示、未授权时手动粘贴回退。
- 分类筛选及选中状态、名称唯一性、保存失败回滚、收藏淘汰和清空保留收藏。
- 搜索结果正确，索引建立后筛选不再读取 payload 字节。

与审查使用相同的 50 条 × 1 MiB 人工 payload，本轮更新查询并筛选约 0.074 ms；审查时单次筛选约 52.5 ms。两者均为本机有界样例，不是完整键盘输入到屏幕渲染的耗时，也不包含首次建立摘要索引的开销。

隔离 GUI 已验证方向键滚动跟随、Tab 焦点与 Enter 操作对象一致、分类空名/重名错误及输入保留、修正名称后的保存、富文本预览、RTFD 附件首次可见、关闭按钮与 Esc 返回、设置外观及快捷键录制的辅助功能信息。粘贴只写独立命名剪贴板；系统按键发送、全局快捷键和登录项变更未启用。

菜单状态订阅另经调用链检查；没有将验证副本的菜单当成安装版实机验收。后续已确认真实签名 App 的首次迁移和数据一致性。新安装版的辅助功能自动粘贴、全局快捷键、登录启动和多屏未完成实机验收；UI 工具无法连接其菜单栏界面，不据此判定功能故障。

## 实施注意

- 数据模型字段保持不变，搜索索引使用内存缓存，避免为性能修复额外引入数据模型升级。
- 旧库不自动清除；切回旧版本只会看到迁移前数据，详见首次运行说明。
- 迁移使用 [Apple 的 replacePersistentStore API](https://developer.apple.com/documentation/coredata/nspersistentstorecoordinator/replacepersistentstore(at:destinationoptions:withpersistentstorefrom:sourceoptions:type:))，没有手工拼接 SQLite 与 WAL 文件。

## 安装后反馈：采集开关语义

旧设置使用“暂停剪贴板采集”并直接绑定 `isPaused`，导致开关亮起实际表示暂停，容易被理解为开启采集。已改为“开启剪贴板采集”，通过反向绑定保留原暂停状态的存储语义，并显示“正在采集”或“已暂停”的说明。

修复后 Release 构建及同身份签名通过，已更新日用 App。实机确认开启时一条人工文字入库、关闭时另一条人工文字不入库，恢复后也不补录暂停期间的文字。最终开关开启，`monitorPaused=false`。这次仅验证采集开关与记录行为，没有重复无关格式或自动粘贴测试。
