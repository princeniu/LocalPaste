# 下一阶段：完成本地首版验收

状态：建议顺序，不表示已授权新功能开发或覆盖当前安装版。

## Now：验收收尾

执行方：Agent；涉及系统授权时由用户确认。时间窗口：下一轮有界验证，不承诺未评估的工时。

1. 完成暂停/恢复与非敏感应用排除的实机验证。每次先确认搜索框实际值与所选分类，不能把搜索失败当成样例未采集。
2. 用隔离数据环境验证上限设置和清空确认 UI，保留真实剪贴板历史不动。现有存储层隔离验证已通过，不重复搭建测试框架。
3. 补齐必要的 URL、键盘路径与未覆盖格式；多屏仅有真实硬件时实测。
4. 只修真实复现的问题，修后只复核对应场景。不做全面重构或新一轮扩展审查。

退出标准：首版本地常用路径有明确通过/失败/受阻结论；隐私控制没有未解释的失败；当前安装版可回退。硬件限制与未做的异常场景单独记录。

## Next：日用打磨

在上一阶段结束后，由用户使用几天并反馈实际阻碍，Agent 按频率和影响只处理最需要的项。

优先关注卡片可读性、预览关闭/返回、搜索焦点、键盘效率，以及固定的 Release 构建和签名交付流程。登录启动作为候选功能，另行确认后实现。

退出标准：用户常用工作流无需切回原剪贴板工具，迭代不会无故覆盖已确认基线。

## Later：按需求增强

备份导入导出、OCR、批量顺序粘贴分别按真实需求立项。iOS/iCloud 同步是独立阶段。当前不做 AI、账号系统、对外发布或功能堆叠。
