# 下一阶段：稳定日用版

状态：建议顺序，不表示已授权新功能开发或覆盖当前安装版。

## Now：修复版安装验收

执行方：Agent；涉及系统授权时由用户确认。时间窗口：下一轮有界验证，不承诺未评估的工时。

1. 修复版已完成签名安装、旧库迁移、数据一致性检查和记录开关实机验证，原 App 与数据保留可回退副本。
2. 产品体验迭代将设置分为通用、隐私、分类、关于，精简正常状态下的说明，保留操作失败时的详情和必要隐私提示。
3. 构建脚本统一生成 App、ZIP、版本与源码摘要；PR 工作流运行现有回归和 Release 构建。
4. 仍需补齐当前签名安装版的全局快捷键、目标应用自动粘贴及下一次实际登录启动结果。多屏仅在具备硬件时验证，不重复全库审查。

退出标准：首版本地常用路径有明确通过/失败/受阻结论；隐私控制没有未解释的失败；当前安装版可回退。硬件限制与未做的异常场景单独记录。

## Next：日用打磨

在上一阶段结束后，由用户使用几天并反馈实际阻碍，Agent 按频率和影响只处理最需要的项。

优先记录误操作、搜索或焦点阻碍、粘贴失败等真实问题，按频率与影响处理。正常使用 3–5 天后再决定新增功能；登录启动已实现，其实际登录结果按上文记录。

退出标准：用户常用工作流无需切回原剪贴板工具，迭代不会无故覆盖已确认基线。

## Later：按需求增强

备份导入导出、OCR、批量顺序粘贴分别按真实需求立项。iOS/iCloud 同步是独立阶段。当前不做 AI、账号系统、对外发布或功能堆叠。
