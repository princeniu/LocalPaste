# 下一阶段：完成本地首版验收

状态：建议顺序，不表示已授权新功能开发或覆盖当前安装版。

## Now：修复版安装验收

执行方：Agent；涉及系统授权时由用户确认。时间窗口：下一轮有界验证，不承诺未评估的工时。

1. 原安装版的常用往返、暂停/排除、上限和清空验收已记录在 STATUS.md，不重复将它们作为未完成事项。
2. 当前工作区包含全库审查修复及登录启动。先查看修复版的隔离回归与 GUI 记录，再安排稳定签名的候选安装。
3. 安装前退出旧版本，保留原 App 与旧库；候选首次打开时检查迁移后历史、收藏、分类以及辅助功能授权。
4. 登录启动仍需真实安装环境中的启用、批准和后续登录验收；多屏仅有真实硬件时实测。只补齐剩余必要场景。

退出标准：首版本地常用路径有明确通过/失败/受阻结论；隐私控制没有未解释的失败；当前安装版可回退。硬件限制与未做的异常场景单独记录。

## Next：日用打磨

在上一阶段结束后，由用户使用几天并反馈实际阻碍，Agent 按频率和影响只处理最需要的项。

优先关注卡片可读性、预览关闭/返回、搜索焦点、键盘效率，以及固定的 Release 构建和签名交付流程。登录启动已经实现，系统级验收按上文单独记录。

退出标准：用户常用工作流无需切回原剪贴板工具，迭代不会无故覆盖已确认基线。
